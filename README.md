# Kleeto

A real computer, rented by the second, paid for by the agent that uses it.

An agent asks for a machine over HTTP. It gets a `402 Payment Required` carrying a
per-second price, pays it in USDC on Hedera from its own account through an x402
facilitator, and the machine comes up: a browser, a headless Linux box, or a full Linux
desktop it can open applications on. Every second the machine runs is a hash-chained
checkpoint on a public Hedera Consensus Service topic, and every file it produces is
hashed into a receipt anyone can recompute from Hedera's mirror node without a key or an
account.

Built for the Hedera "AI and Agentic Payments" bounty. `hedera:testnet`.

## Layout

| Path | What it is |
| --- | --- |
| `landing/` | The site (Next.js 16, React 19, Tailwind v4). The Kleeto page is the root route; the earlier reference clones live at `/solari`, `/runloop`, `/browsers`, `/desktops`, `/sandboxes`. |
| `src/` | The lane catalogue and the Solari adapter the capture scripts drive. |
| `scripts/` | Everything that produced the site's imagery: shoot scripts that drive real leases, the film build pipeline, and the measurement checks used to verify a render. |
| `videos/kleeto-hero-film/` | The hero film as a HyperFrames composition. `opening.part.{html,css,js}` are the opening; `index.html` is generated by `scripts/build-film-final.mjs`. |
| `research/` | Positioning, rate maths, workflow catalogues, and the live provider tests behind the lane specs. |
| `agent-runs/` | Beat and pointer logs from each capture session. The recordings themselves are not committed. |

## Working on it

```sh
cd landing && npm install && npm run dev     # the site on :3000
npm run check                                # lint, typecheck, build
```

Rebuilding the hero film needs the raw takes, which are not in the repo:

```sh
node scripts/build-film-final.mjs            # cuts the shots and writes index.html
cd videos/kleeto-hero-film && npx hyperframes render -o out/film.mp4 -q high
```

Every image and video on the site is a capture of a real lease. Nothing is a mockup.

## Provenance

`landing/` began as [JCodesMore/ai-website-cloner-template](https://github.com/JCodesMore/ai-website-cloner-template)
and keeps that scaffold's Next.js, Tailwind and shadcn setup. Everything under
`landing/src/components/kleeto` and `landing/src/shaders` is this project's own.

## Configuration

Copy `.env.example` to `.env`. The facilitator's fee payer is resolved from its
`/supported` response at runtime and is never hardcoded.
